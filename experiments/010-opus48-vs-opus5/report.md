## 관찰

1. **EXP-009의 발견이 동시점·동일 하네스에서 완전 재현됐다.** "산출량 확대 프로파일"(더 많은 출력·더 많은 커밋·더 긴 시간)은 서빙 시점이나 계측 방식의 아티팩트가 아니라 Opus 5의 실재 특성이다. 특히 output 토큰은 6 run 전체에서 단 한 건의 역전도 없이 갈렸다.
2. **속도-규율 트레이드오프의 순수 계수**: 같은 날·같은 과제에서 Opus 5는 평균 +64% 시간과 +37% 출력으로 커밋 규율 4배(평균 1.3 → 5.7개)와 검증·문서화 행동을 산다. 최속 run(5-3, 9.4분)은 4.8 평균에 근접하면서도 커밋 4개를 유지 — 프로파일은 유지하되 속도 변동은 있다.
3. **완주 신뢰성은 양 세대 동등**: 6/6 iteration 1 완주, 허위 신고 0, 게이트 정당 기각 0 (1건은 하네스 오검).
4. Opus 4.8은 EXP-002(3일 전) 대비 en 기준 6–7분 → 7.8–8.7분으로 소폭 느려졌으나 같은 자릿수 — 동시점 재측정의 가치 확인.
