## 관찰

1. **완주 재현성은 세 조건 모두 견고하다.** 9/9 완주, 8/9가 iteration 1. 유일한 예외 sol-2(iter 2)도 랄프 루프가 정상 흡수 — 완주 판정 관점에서 세 조건은 "우연한 1회"가 아니었다.
2. **완주 외 지표는 run 간 변동이 크다.** kimi-k3는 21분→7분대(커밋 4→1–2, output 31K→14K)로 절반 이하, 궤적 프로파일 자체가 달라졌다. S축 실험들(EXP-002/004)에서 본 "궤적 변동은 상수 노이즈" 결론이 M축·직결 스택에서도 재확인 — n=3으로도 효율 순위 서사는 불가하며, 완주율만이 안정된 지표다.
3. **measure v4 게이트가 6 run 연속 무오검** — EXP-015에서 수정한 CWD 기반 포트 탐지의 실전 검증을 겸했다.
