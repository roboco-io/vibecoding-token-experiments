EXP-013/014/016에서 qwen3.8-max·kimi-k3는 영문 정본 조건으로 각 3/3 완주를 기록했다. 본 실험은 **프롬프트와 산출물 언어를 한국어로 반전**한 조건에서 두 모델의 완주율을 측정한다 — 중국계 모델의 한국어 지시 수행·한국어 산출 능력 검증이 목적. 기존 en 결과(각 n=3)와 대칭 구조라 모델 내 en vs ko 완주율 비교가 성립한다.
