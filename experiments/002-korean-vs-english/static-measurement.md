# EXP-002 정적 측정: 동일 내용 KO/EN 문서쌍 토큰 비율

- 측정일: 2026-07-21
- 방법: 유효 API 키 부재로 count_tokens 대신 **세션 로그 usage 차분법** 사용 — 동일 지시문에 문서만 바꿔 넣은 haiku 세션들의 첫 응답 `input + cache_creation`에서 워밍 베이스라인(문서 없음)을 차감. 시스템 오버헤드는 차감으로 상쇄됨. 실행 순서상 캐시 상태(cache_read 21,900)가 문서 4회·베이스라인에서 동일함을 확인.

## 결과

| 문서쌍 | 내용 성격 | KO 토큰 | EN 토큰 | 비율 KO/EN |
|--------|----------|--------:|--------:|-----------:|
| EXP-001 보고서 발췌 (동일 범위 번역쌍) | 표·수치·코드 식별자 다수 | 1,364 | 978 | **1.39** |
| EXP-002 프롬프트쌍 (ko.md / en.md) | 산문·지시문 위주 | 830 | 301 | **2.76** |

## 해석 (동적 실험의 기준선)

- **산문 위주 텍스트에서 한국어는 영어의 약 2.8배** 토큰을 사용한다. 표·숫자·코드 식별자가 많이 섞이면 언어 중립 토큰이 희석해 1.4배 수준까지 내려간다.
- 동적 실험에서 에이전트 산출물은 코드(언어 중립) + 문서/주석/보고(언어 종속)의 혼합이므로, KO/EN billable 차이는 **1.4~2.8배 사이의 가중 평균**으로 나타날 것으로 예상. output 토큰에서 가장 크게, cache_creation(자기 산출물 재독)에서 2차로 나타나야 정합적.

## 한계

- 번역쌍 2개(n=2 문서), 문서 크기 소형 (1~1.4K 토큰)
