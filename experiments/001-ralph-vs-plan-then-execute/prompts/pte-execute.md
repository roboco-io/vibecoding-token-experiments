# plan-then-execute 실행 세션 프롬프트 (태스크당 새 세션)

`<TASK_SPEC>`을 태스크 명세 경로로 치환해 사용한다.

---

`<TASK_SPEC>` 문서를 읽고 그 태스크만 구현하라.

- 명세에 적힌 범위를 벗어나지 않는다. 다른 태스크의 파일은 명세에 적힌 인터페이스로만 참조한다.
- 명세의 완료 기준을 검증한 뒤, `<TASK_SPEC>`의 `## 완료 기록` 섹션에 다음을 기록하라: 구현한 파일 목록, 후속 태스크가 알아야 할 인터페이스 변경·특이사항.
- 완료 기록 작성 후 세션을 종료한다. 다른 태스크를 이어서 진행하지 않는다.
