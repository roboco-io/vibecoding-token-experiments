# EXP-004 결과 보고: Ralph loop + 스킬 구조

- 실험일: 2026-07-21
- 가설: [S-03](../../hypotheses/catalog.md) — 단일 세션 ralph에 도메인 계약 스킬을 제공하면 billable이 감소한다
- **판정: 보류 (사실상 효과 없음)** — 평균 차 +3.5%(방향은 가설 반대)가 조건 내 변동폭(200K)에 완전히 묻힘

## 핵심 발견

1. **단일 세션에서 점진 공개는 성립하지 않는다.** 두 run 모두 Skill 도구 호출 0회 — 세션 초반에 **6개 SKILL.md를 전부 Read**했다. 전체 과제를 혼자 수행하는 세션은 어차피 모든 계약이 필요하므로 "필요한 것만 로드"가 무의미하다. 스킬의 절약 메커니즘(부분 로드)은 **세션이 전체 컨텍스트의 부분집합만 필요할 때**(=PTE의 태스크 세션)만 작동한다 — EXP-003(-39.3%)과의 결정적 차이.
2. **스킬은 아키텍처 가이드로는 작동했다.** 두 run 모두 스킬이 정의한 구조(serializers/·auth/·에러 규약)를 그대로 따랐고 첫 이터레이션에 154/154 통과. 품질 안정화 효과는 있으나 기준 ralph도 이미 100% 통과였으므로 이 과제에서는 차별점이 아님.
3. **궤적 변동이 다시 지배 변수.** 동일 처치의 두 run이 199K vs 400K(2배). EXP-002에 이어 재확인 — 단일 세션 실험에서 ±수십만 토큰의 run 간 변동은 상수처럼 존재하며, n=2로는 ~10% 수준의 효과를 판별할 수 없다.

## 시사점 (EXP-001~004 종합)

- 스킬(점진 공개)의 토큰 가치는 **멀티 세션 워크플로에서만** 실현된다: PTE에서는 -39.3%(EXP-003), 단일 세션에서는 ~0(본 실험).
- 단일 세션이 가능한 과제라면: 스킬 유무와 무관하게 **단일 세션 자체가 최적** (기준 ralph 289K ≈ 스킬 ralph 299K ≪ 스킬 PTE 1,724K ≪ PTE 2,840K).

## 한계

- n=2, 궤적 변동으로 ±10% 효과는 식별 불가. 스킬 작성 비용(EXP-003 계획 세션에 포함)은 본 실험 측정 외 — "기존 스킬 재사용" 시나리오.
