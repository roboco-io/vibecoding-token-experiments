# EXP-004: Ralph loop + 스킬 구조

> 실행 절차·프롬프트: 본 문서와 [runs/](runs/) 참조 (EXP-002 ralph 절차 재사용)

## 가설

[S-03](../../hypotheses/catalog.md): 단일 세션 ralph에 도메인 계약 스킬(점진 공개 컨텍스트)을 제공하면, 스펙 탐색·시행착오가 줄어 스킬 없는 ralph 대비 billable 토큰이 감소한다.

## 조건

| 조건 | 설명 | 데이터 |
|------|------|--------|
| ralph-skills (신규, n=2) | EXP-002 KO 프롬프트 + 스킬 안내 1줄. 작업 리포에 EXP-003 계획 세션이 산출한 도메인 스킬 6개를 사전 배치 | `runs/skills-1/`, `runs/skills-2/` |
| ralph 기준 (재사용, n=2) | EXP-002 ko-1(270,352)·ko-2(307,930) — 동일 프롬프트·언어, 스킬 없음. 평균 289,141 | EXP-002 runs |

## 통제 변수

- 프롬프트: EXP-002 ko.md와 동일 + 스킬 안내 1줄만 추가 (언어·완료 기준 동일)
- 스킬: EXP-003 산출물 6개를 수정 없이 복사 (내용 통제). 스킬 작성 비용은 본 실험 측정에 미포함 — "이미 존재하는 스킬의 재사용" 시나리오
- 완료 판정: Hurl 13파일/154요청 100% (독립 재검증), Opus 고정, headless, 무개입
