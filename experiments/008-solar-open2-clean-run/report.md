## 관찰 — M축 서사의 완결

1. **오염 제거가 결정 변수.** EXP-007 부검이 지목한 오염(superpowers 훅·글로벌 CLAUDE.md 주입)을 격리 `CLAUDE_CONFIG_DIR`로 제거하자, 동일 모델·동일 PROMPT·동일 env에서 미완주(3/13)가 완주(13/13)로 뒤집혔다. 완주가 iteration 10에 이루어져 EXP-006 상한(15) 안쪽이므로 상한 상향(30)은 결과에 기여하지 않았다. 외부 kill·슬립도 0회(caffeinate + 터미널 분리 기동).
2. **행동 계층도 개선.** 커밋 0회 → 4회(한국어, 작업 단위별), 허위 완료 신고 0회, 첫 완료 신고가 곧 실제 완주. EXP-006에서 확립된 TDD 루프는 유지·강화(iteration 3·6은 35분급 세션 내 수정-검증 루프).
3. **모델 내재 결함은 잔존하나 완주를 막지 못했다.** iteration 1의 허락-대기("진행하시겠습니까?" 후 종료)는 무오염 환경에서도 재현 — 모델 내재로 확정. thinking이 출력 문자의 94%(1.43M자)로 EXP-006(95%)과 동일한 폭주 성향. iteration 9의 회차 경계 실행 불가 상태. 랄프 루프의 반복 구조가 이 결함들을 흡수했다.
4. **`.ralph-done` 외부 검증 게이트는 이번엔 발동 없이 통과**했지만, iteration별 자동 채점(수렴 곡선)과 함께 재현 가능한 완주 판정 인프라로 확립됐다.

## 결론·후속

- **M-04 검증. Solar Open 2는 무오염 환경의 Claude Code 랄프 루프로 RealWorld 백엔드를 무개입 완주할 수 있다.** M축 4실험의 서사: 자율성 부재(EXP-005) → TDD 확립·미완주(EXP-006) → 실패 원인 3계층 분해(EXP-007) → 오염 제거 후 완주(EXP-008). "모델이 완주 못 한다"로 보였던 것의 지배 요인은 실험 환경 오염이었다.
- 방법론 교훈: **자율 루프 실험에서 실험자 로컬 환경(훅·글로벌 설정) 격리는 선택이 아니라 전제 조건**이다. 이를 어긴 EXP-005·006의 자율성 관련 판정은 재해석이 필요하다(EXP-007 보고 참조).
- 비용 비교(M-02의 잔여 질문)는 단가 공개·캐시 보고가 갖춰져야 판정 가능 — Upstage 콘솔 실과금 확인이 유일한 경로로 남아 있다.
